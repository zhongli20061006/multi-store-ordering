# 原型验收真源

## 验收范围

阶段一「本地原型」的可验收结果为：

1. 顾客端完整点单一单成功；
2. 商家后台可登录并完成门店/菜单/订单管理；
3. 数据落库可查、金额正确、状态机正确；
4. 越权/非法输入有明确拒绝。

## 顾客走查（微信开发者工具）

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 打开小程序 | 看到营业中门店列表 |
| 2 | 选择门店 | 进入菜单，分类与商品正确 |
| 3 | 加购若干商品 | 购物车合计与后端一致 |
| 4 | 填写姓名/电话/备注并提交 | 成功页显示订单号；重复点击不产生重复订单 |
| 5 | 我的订单输入电话 | 看到该订单，状态为待接单 |
| 6 | 打烊门店/下架商品 | 不可下单并提示 |

## 商家走查（浏览器）

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 登录 | 进入后台 |
| 2 | 新增门店并开启 | 列表可见、顾客端可见该店 |
| 3 | 编辑菜单 | 顾客端菜单同步变化 |
| 4 | 接单 | 订单状态变为已接单，顾客端可见 |
| 5 | 完成/取消 | 状态迁移正确，非法迁移被拒 |
| 6 | 标记付款 | 支付状态变为已付款 |
| 7 | 越权测试 | 篡改 token 或访问他店数据返回 401/403 |

## 证据要求

- 后端：自动化接口测试通过 + 关键接口手工请求输出。
- 前端：微信开发者工具截图/录屏 + 浏览器截图。
- 数据：订单落库查询结果（金额、状态、明细快照）。
- 安全：越权与非法状态请求的拒绝结果。

## 验收结论

全部通过 → 阶段一 closeout；存在阻断问题 → 修复后复验；未验证项如实列出。
