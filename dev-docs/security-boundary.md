# 安全边界真源

## 身份与权限

- 商家后台：用户名+密码登录，bcrypt 哈希，JWT（HS256，过期时间）。初始账号由种子脚本生成，密码以环境变量/首次登录提示方式提供，禁止硬编码进源码。
- 顾客端：本阶段不登录；「我的订单」按电话查询，仅返回本人订单摘要，不返回他人隐私字段（如其他顾客备注）。
- 所有管理接口校验门店归属；非法越权返回 403 并记录日志。

## 输入与金额

- 所有入参经 Pydantic 校验；字符串限长、枚举严格。
- 订单金额与单价一律以后端数据库价格为准重算；前端提交的价格字段被忽略。
- 限库存商品由后端原子扣减，客户端不得提交数量之外的可信字段；库存不足整单拒绝。
- 禁止 SQL 拼接；全部走 SQLAlchemy 参数化。

## 数据与隐私

- 顾客电话属于个人信息：本阶段仅用于订单联系与查询；不导出、不用于营销。上线前需按微信平台隐私政策补充协议文案（未验证）。
- 数据库文件仅本机；.gitignore 已排除 *.db。

## 密钥与配置

- JWT 密钥、种子管理员密码、后续第三方凭据一律经 `.env`（不入库、不进 Git）；提供 `.env.example`。
- 生产环境禁止调试模式与默认弱口令（本阶段不部署，此项未验证待阶段二）。

## 二期安全项（未验证，实施前核查）

- 微信登录 code2session 签名校验。
- 微信支付回调验签、幂等、退款权限。
- 美团/抖音开放平台接口签名、沙箱、额度与失败重试。
- 正式部署的 HTTPS、域名备案、日志脱敏。

## 红线

- 前端输入不可信；身份、金额、状态、数据归属必须服务端重新校验。
- 密钥不得进源码/日志/Git 历史。
- 缺失证据标 `未验证`，不得声称安全或可上线。
